Tämä Bingo yksinpeli on tehty yhteistyössä työkaveri Jaakko Vallinkoski kanssa.

ASENNUSOHJEET:

Lataa Bingo.html, Bingo.js ja styles.css samaan kansioon ja käynnistä peli Bingo.html tiedostosta.

PELI:

Aloita näppäintä painamalla käynnistyy peli. Arvontanopeuden voi säätää 1-10 sekunnin väliin.
Voit myösarpoa vain yhden numeron.

Käynnissä olevan pelin voi myös pysäyttää ja käynnistää uudestaan.

Huijauksenesto: jos klikkaa solua jota ei olla arvottu, peli pysähtyy ja ilmoittaa.

Pelistä löytyy automaatio, joka "pelaa" itsestään kunnes Bingo tai 65 kierrosta tulee täyteen.
Jos haluat muokata kierrosten määrää, muuta tätä lukua:
if (arpanumerot.length >= 64)

Bingo.js sisältää kommentteja ja funktiot ovat nimetty helposti ymmärrätteväksi.
